# Conceito visual aprovado

Telas do protótipo de conceito do Trama, no formato do canvas de design onde foram criadas.
São referência visual para as Tasks 6, 12, 13 e 14 do plano: cores, tamanhos, textos, glyphs e animações.

- `Main.dc.html` — A semana do Theo (trama semanal, cartão de padrão, botão "Dar um ponto")
- `Registro.dc.html` — Dar um ponto (grade de tipos, confirmação "Ponto dado.")
- `Mes.dc.html` — O mês do Theo (pôster 1080×1350 gerado a partir de dados simulados)

Os arquivos usam marcação própria do canvas (`<x-dc>`, `{{...}}`, `<sc-for>`), então não abrem
direto no navegador. Leia o HTML, o CSS e o SVG como especificação visual; os dados são fictícios.
Onde o spec e o conceito divergem, vale o spec (ex.: trechos de linha derivados dos pontos,
cores com contraste corrigido).
